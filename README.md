# Funngro - Teen Freelancing & Employer Platform

A responsive, high-performance, and SEO-optimized web application for **Funngro** (India's leading platform connecting smart teen freelancers with real companies).

## Features
- **Page 1: Teen Freelancer Hub (`index.html`)** — Earn via web dev, design, content, and marketing tasks paid directly via UPI.
- **Page 2: Company / Employer Portal (`company.html`)** — Hire motivated teen freelancers for agile micro-projects and Gen-Z brand insights.
- **Modern UI Styling (`styles.css`)** — Dark theme palette (`#0d1117`), neon emerald green accents (`#10b981`), pure white typography, and glassmorphism cards.
- **Technical SEO & Performance** — Semantic HTML5 tags, strict single-`<h1>` heading hierarchy, OpenGraph / Twitter cards, and Schema.org JSON-LD structured data.

## Quick Start / Local Server

```bash
# Using Python standard library
python -m http.server 3000
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.
